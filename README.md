# NorIDE
<img width="521" height="521" alt="NorIDE_Logo" src="https://github.com/user-attachments/assets/6c422a4f-2016-4cf7-b025-e3cbb2f37493" />

A Lightweight, versatile IDE for beginners to experienced coders!

# What does NorIDE actually do?
NorIDE is a versatile IDE deigned to be as versatile as possible, while having a sleek and minimalistic GUI. The program can create, open, edit, run and save files from multiple languages. 
****
NorIDE features compatability for:\
\
• General-Purpose & Systems Languages:\
Python, JavaScript, TypeScript, C++, C, C#, Go, Rust, Swift, Assembly\
• Scripting & Data Science Languages:\
Lua, PHP, Ruby, Ruby on Rails, Perl, R ,Shell (automatically locates Git Bash on Windows)\
• Web, Data & Query Languages (Opens automatically in browser):\
HTML, CSS\
•Data & Query Languages & Other:\
SQL, JSON, YAML, XML, Plain Text\
****

# How to run the program
1. Download the files and dezip the folder
2. Open the 'dist' folder and run the 'NorIDE.exe' file
3. Enjoy!
****
